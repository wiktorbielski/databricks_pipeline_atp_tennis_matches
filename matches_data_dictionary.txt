Tennis Tournament Data Fields

tourney_id:
- A unique identifier for each tournament, such as "2020-888".
- The first four characters always represent the year.
- The rest of the ID does not follow a predictable structure.

tourney_name:
- Name of the tournament.

surface:
- Type of surface the tournament is played on.

draw_size:
- Number of players in the draw.
- Often rounded up to the nearest power of 2 (e.g., 28 players might be shown as 32).

tourney_level:
- For men:
  - 'G' = Grand Slams
  - 'M' = Masters 1000s
  - 'A' = Other tour-level events
  - 'C' = Challengers
  - 'S' = Satellites/ITFs
  - 'F' = Tour finals and season-ending events
  - 'D' = Davis Cup
- For women:
  - 'P' = Premier
  - 'PM' = Premier Mandatory
  - 'I' = International
  - Levels of ITFs indicated by prize money (e.g., '15' = ITF $15,000)
  - Older WTA designations (e.g., 'T1' for Tier I)
  - 'D' for Federation/Fed/Billie Jean King Cup, Wightman Cup, Bonne Bell Cup
- Others for both genders:
  - 'E' = Exhibition (non-tour sanctioned events)
  - 'J' = Juniors
  - 'T' = Team tennis (not yet in dataset)

tourney_date:
- Eight digits, format YYYYMMDD.
- Typically the Monday of the tournament week.

match_num:
- A match-specific identifier.
- Often starts from 1, sometimes counts down from 300, or can be arbitrary.

winner_id:
- The player_id for the winner of the match.

winner_seed:
- Seed number of the winner.

winner_entry:
- Entry status of the winner:
  - 'WC' = Wild card
  - 'Q' = Qualifier
  - 'LL' = Lucky loser
  - 'PR' = Protected ranking
  - 'ITF' = ITF entry

winner_name:
- Name of the winner.

winner_hand:
- Serving hand of the winner:
  - 'R' = Right
  - 'L' = Left
  - 'U' = Unknown (For ambidextrous players, this is their serving hand)

winner_ht:
- Height of the winner in centimeters, where available.

winner_ioc:
- Three-character country code of the winner.

winner_age:
- Age of the winner, in years, as of the tourney_date.

loser_id:
- The player_id for the loser of the match.

loser_seed:
- Seed number of the loser.

loser_entry:
- Entry status of the loser.

loser_name:
- Name of the loser.

loser_hand:
- Serving hand of the loser.

loser_ht:
- Height of the loser in centimeters, where available.

loser_ioc:
- Three-character country code of the loser.

loser_age:
- Age of the loser, in years, as of the tourney_date.

score:
- Match score.

best_of:
- Number of sets in the match ('3' or '5').

round:
- Round of the match.

minutes:
- Length of the match, where available.

Statistics for Winner:

w_ace:
- Number of aces by the winner.

w_df:
- Number of double faults by the winner.

w_svpt:
- Number of serve points by the winner.

w_1stIn:
- Number of first serves made by the winner.

w_1stWon:
- Number of first-serve points won by the winner.

w_2ndWon:
- Number of second-serve points won by the winner.

w_SvGms:
- Number of serve games by the winner.

w_bpSaved:
- Number of break points saved by the winner.

w_bpFaced:
- Number of break points faced by the winner.

Statistics for Loser:

l_ace:
- Number of aces by the loser.

l_df:
- Number of double faults by the loser.

l_svpt:
- Number of serve points by the loser.

l_1stIn:
- Number of first serves made by the loser.

l_1stWon:
- Number of first-serve points won by the loser.

l_2ndWon:
- Number of second-serve points won by the loser.

l_SvGms:
- Number of serve games by the loser.

l_bpSaved:
- Number of break points saved by the loser.

l_bpFaced:
- Number of break points faced by the loser.

Rank Information:

winner_rank:
- ATP or WTA rank of the winner, as of the tourney_date or the most recent ranking date before it.

winner_rank_points:
- Number of ranking points of the winner, where available.

loser_rank:
- ATP or WTA rank of the loser.

loser_rank_points:
- Number of ranking points of the loser.
